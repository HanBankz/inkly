# Inkly

A real-time collaborative whiteboard — multiple people draw, write, and talk on the same canvas at once, live.

## Features
Shared drawing canvas — brush, eraser, shapes, text, eyedropper and region blur, all synced instantly across every connected device.
Presence — an avatar stack shows who's currently in the room.
Undo/redo per user — each person can undo their own last action
Host controls — the room creator can clear the whole canvas
Export — save the canvas as a PNG straight to your device's gallery.
In-room voice calls
Reconnect-safe — leave and rejoin a room

## Tech Stack
- Flutter / Dart
-  Supabase, livekit, WebSocket
-  Postgres
-  Row Level Security (RLS)
-  Edge Functions (Deno/TypeScript)
-  WebRTC-based real-time audio
